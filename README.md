# Open Dental Atlas

A browser-based 3D viewer for real intraoral dental scans from the Teeth3DS+ dataset.

This repository is a bootstrap skeleton. The project description, credits, and run guide will be filled in later.

## Scripts

```bash
npm install
npm run dev
```
